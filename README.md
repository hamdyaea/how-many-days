# How Many Days Have You Lived?

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** GPL v3 (see LICENSE).

A Python 3 application calculating the exact number of calendar days between a birth date and today. Modern Tkinter GUI, validated ISO date input and CLI mode. No network access or external Python packages are needed.

```sh
python3 HowManyDays.py
python3 HowManyDays.py --name Alice --birthdate 2000-01-01
python3 -m unittest discover -s tests -v
```

Original EasyGUI version: [old branch](https://github.com/hamdyaea/how-many-days/tree/old).
